# Как начать сессию с Claude

Вставить в начало нового чата (или в project instructions):

---

```
Проект ЧИТАТЕЛЬ — iOS-приложение книжного клуба (Flutter + Express + MongoDB).

Документы в репо (папка docs/):
- AI-CONTEXT.md — ПРОЧИТАЙ ПЕРВЫМ, там статус, правила, текущая задача
- MASTER.md — спецификация (экраны, API, схемы, Apple rules)
- STEP-BY-STEP.md — план из 46 задач с файлами и чеклистами
- prototype-v4_2.jsx — прототип UI (открыть в браузере)

Правила:
1. Начни с AI-CONTEXT.md — там твоя роль и ограничения
2. Делай ТОЛЬКО текущую задачу из STEP-BY-STEP
3. НЕ создавай лишних файлов, НЕ обрезай код, НЕ добавляй фичи вне спеки
4. Если неясно — спроси, не угадывай
5. После завершения задачи — обнови AI-CONTEXT.md в репо
```

---

Для конкретной задачи добавить строку:

```
Текущая задача: 2.7 (аудиоплеер)
```
