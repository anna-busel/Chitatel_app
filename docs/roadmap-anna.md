# ЧИТАТЕЛЬ - План разработки

## Сроки и этапы

| Период | Этап | Результат |
|--------|------|-----------|
| Месяц 1 (15 фев - 15 мар) | Документация, архитектура, настройка рабочего окружения | Спецификация, прототип всех экранов, GitHub, структура проекта |
| Месяц 2 (15 мар - 15 апр) | Сервер, база данных, API авторизации, дизайн-система, навигация, экраны входа | Можно войти через Apple/Google/Email, базовый интерфейс |
| Месяц 3 (15 апр - 15 май) | API каталога, аудио-стриминг, экраны каталога и книги, полноценный аудиоплеер, мини-плеер | Каталог, поиск, плеер (фоновое воспроизведение, скорость, таймер сна) |
| Месяц 4 (15 май - 15 июн) | Интеграция Apple Pay, paywall, управление подписками, API клуба, чат (реальное время), Q&A, модерация | Оплата через App Store + живой чат + вопросы-ответы |
| Месяц 5 (15 июн - 15 июл) | Интеграция OpenAI, API дневника, экраны цитат и анализа, push-уведомления, профиль и все подэкраны | Дневник цитат, ИИ-анализ, уведомления, профиль |
| Месяц 6 (15 июл - 15 авг) | Онбординг, accessibility, обработка ошибок, админ-панель (6 экранов), seed-данные, TestFlight | Админка для Анны, финальное тестирование |

После 6 месяцев - публикация в App Store (1-3 недели на ревью и возможные доработки по замечаниям Apple).

Android-версия: приложение разрабатывается на Flutter, что позволяет запустить Android после стабилизации iOS-версии без переписывания кода.

## Расходы

| Что | Зачем | Когда | Сумма |
|-----|-------|-------|-------|
| Apple Developer Account | Тестирование на iPhone, публикация | Месяц 2 | 99 USD/год |
| Сервер (Contabo VPS) | Бэкенд: данные, аудио, аккаунты, чат | Месяц 2 | ~7-15 USD/мес |
| OpenAI API | ИИ-анализ цитат | Месяц 5 | ~5-15 USD/мес |

Домен: можно использовать поддомены annabusel.org. Для самостоятельного продукта рекомендуется отдельный домен (~10-15 USD/год) - профессиональнее для App Store и удобнее для продвижения.

## Что нужно от Анны

| Что | Зачем | Когда |
|-----|-------|-------|
| Apple Developer Account (99 USD) | Без него нельзя тестировать на iPhone | Месяц 2 |
| 2-3 аудиофайла (можно черновики) | Тестировать плеер | К началу Месяца 3 |
| Описания + обложки тестовых книг | Наполнить каталог | К началу Месяца 3 |
| Цены на тарифы (в USD) | Настроить оплату в App Store | К началу Месяца 4 |

## Отслеживание прогресса

В конце каждого месяца - демонстрация на TestFlight (тестовая версия на iPhone).
