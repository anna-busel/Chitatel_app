## РАСХОЖДЕНИЯ С MASTER.md (ВАЖНО для будущих сессий)

**Схема Book в модели расширена vs MASTER секция 7.3.** Источник истины для схемы — `server/src/models/Book.js`, НЕ MASTER.md. MASTER.md описывает общую архитектуру (экраны, API, логика) и не правится. Расхождения — только в полях модели Book.

**Изменения vs MASTER 7.3:**

| Поле в MASTER | Поле в модели (реальность) | Причина |
|---------------|----------------------------|---------|
| `category: enum ['classic', 'psychology']` | `categories: [String]` без enum | У Анны 14 категорий (КРИЗИСЫ, Я — ЖЕНЩИНА, ЛЮБОВЬ, ОТНОШЕНИЯ, ДЕНЬГИ, ОДИНОЧЕСТВО, СМЕРТЬ, СЕМЕЙНЫЕ ОТНОШЕНИЯ, СМЫСЛ ЖИЗНИ, СЧАСТЬЕ, ВРЕМЯ И ПРИВЫЧКИ, ДОБРО И ЗЛО, ОБЩЕСТВО, ПОИСК СЕБЯ). Одна книга может быть в нескольких категориях. |
| (нет) | `tags: [String]` — добавлено | Темы для поиска и AI-рекомендаций. Например «созависимость», «сепарация», «м и ж». Берутся из `targetThemes` Анны. |
| (нет) | `coverImageUrl: String` — добавлено | У Анны есть 50+ готовых PNG-обложек. Основной способ показа обложки. `coverGradientColors` + `coverLabel` остаются как fallback если `coverImageUrl` пусто. |
| `price: Number` (USD) | `priceUsd: Number` + `priceRub: Number` + `priceByn: Number` | У Анны цены в BYN. `priceUsd` — для Apple IAP Product ID. `priceRub`/`priceByn` — для UI/админки/веба в будущем. |
| (нет) | `bookSlug: String` — добавлено | Идентификатор для UTM-ссылок и поиска обложки (имя файла = slug + .png). |
| (нет) | `purchaseUrl: String` — добавлено | Ссылка на внешний сайт anna-busel.com для фоллбека/админки. |

**Миграция при seed:** BYN → USD округлено к Apple Price Tier. **Фактический маппинг в seed.js:**
- 80 BYN → $24.99
- 100 BYN → $29.99
- 150 BYN → $44.99
- 280 BYN (пакеты) → $84.99

**Карточка книги (MASTER 5.4):** если есть `coverImageUrl` — показывать реальную обложку. Если пусто — fallback на градиент из `coverGradientColors` + буквы из `coverLabel` (как в прототипе). Плеер (2.7) использует `coverGradientColors` всегда — это фон ЗА обложкой, не вместо.

**Префикс `asset://` в coverImageUrl:** seed сохраняет URL обложки в формате `asset://book-covers/{slug}.png`. Это НАША внутренняя схема (не стандарт Flutter). Flutter-компонент обложки должен различать префиксы:
- `asset://...` → `Image.asset('assets/book-covers/{file}')`
- `http://...` / `https://...` → `Image.network(url)` (когда появится VPS с обложками)

Обработку делать в одном компоненте (например `BookCoverImage`), чтобы замена схемы в будущем была в одном месте.

**Почему MASTER не правится:** объёмный документ (~140 КБ), риск потерять контекст решений. Синхронизация MASTER с моделью — отдельная задача, когда будет время.
