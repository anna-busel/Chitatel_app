## ❗ ВАЖНОЕ ДЛЯ БУДУЩИХ ЗАДАЧ

**1. Локализация цен (Фаза 3)**

В каталоге, на главной и на экране книги **сейчас** жёстко в долларах ($24.99, $29.99, $44.99) — это **временная заглушка**. Берётся из поля `BookModel.priceUsd` через геттер `displayPriceUsd`.

**В Фазе 3** (задачи 3.1, 3.2):
- Анна создаёт IAP продукты в App Store Connect и задаёт **Apple Price Tier** для каждого
- Подключаем StoreKit 2 (`in_app_purchase`)
- В UI заменяем `book.displayPriceUsd` на `Product.displayPrice` от StoreKit — Apple возвращает **локализованную строку** в валюте Apple ID юзера (₽ для региона Russia, ₺ для Turkey, ₸ для Kazakhstan и т.д.)
- Apple конвертирует валюты сам, обновляет курсы каждые 6 месяцев — нам не делать

**2. Non-consumable IAP для книг и пакетов (пробел в плане)**

В STEP-BY-STEP Фаза 3 говорит про **подписки** (`club.basic.*`, `club.premium.*`), но прямо отмечает: «Non-consumables: пока не создаём (нужны конкретные book_id)».

Когда дойдём до Фазы 3 — оформить как **задачу 3.5: Non-consumable IAP для отдельных книг и пакетов**:
- 42 книги × Product ID = `book.{slug}` (например `book.anna_karenina`)
- 6 пакетов × Product ID = `package.{slug}` (например `package.tolstoy`)
- Маппинг `priceUsd` → ближайший Apple Price Tier
- Поле `appleProductId` в схеме Book уже есть (см. модель)

**3. Кнопка «Купить на сайте» (задача 2.6) — РЕАЛИЗОВАНО**

Реализовано в задаче 2.6: на экране 4.13 (платная) под главной кнопкой добавлена компактная ссылка «Купить на сайте автора →». При тапе — `url_launcher.launchUrl(book.purchaseUrl, mode: externalApplication)` открывает anna-busel.com в браузере.

Формулировка не объясняет «обходные пути» (запрещено Apple), просто «купить на сайте». Визуально не главная кнопка — caption-стиль, серый цвет, подчёркивание. Apple Guideline 3.1.1(a) разрешает такую вторую кнопку.

**4. Заглушки на экране книги (2.6)**

В `_BookContent` есть 3 захардкоженных значения:
```dart
static const bool _isPurchased = false;
static const Set<int> _listenedPartNumbers = <int>{};
static const double _progressPercent = 0.0;
```
**Не путать с моками сервисов** — это просто три boolean/int, которые в Фазе 3 / после 2.7 заменятся на `ref.watch(...)`. Никаких файлов-моков, классов-плейсхолдеров и фейковых провайдеров.

- **Не править код наугад** даже если уверен в гипотезе. Сначала спросить «можно я предположу X и сделаю одну правку Y?». Подождать ОК.

- `flutter clean && flutter pub get && flutter run` — обязательная команда перед диагностикой если есть подозрение на кэш.

**В задаче 2.5 и 2.6 урок применён:** делал в один push, заранее заложил запас высоты карточек, использовал withOpacity вместо withValues, спросил о вариантах ДО написания кода (заглушки vs реальная архитектура).

**Миграция при seed:** BYN → USD округлено к Apple Price Tier:
- 80 BYN → $24.99
- 100 BYN → $29.99
- 150 BYN → $44.99
- 280 BYN (пакеты) → $84.99

**Карточка книги (MASTER 5.4):** если есть `coverImageUrl` — показывать реальную обложку. Если пусто — fallback на градиент из `coverGradientColors` + буквы из `coverLabel` (как в прототипе). Плеер (2.7) использует `coverGradientColors` всегда — это фон ЗА обложкой, не вместо.

**Префикс `asset://` в coverImageUrl:** seed сохраняет URL обложки в формате `asset://book-covers/{slug}.png`. Это НАША внутренняя схема (не стандарт Flutter). Виджет `BookCoverImage` различает префиксы:
- `asset://...` → `Image.asset('assets/book-covers/{file}')`
- `http://...` / `https://...` → `Image.network(url)` (когда появится VPS с обложками)
- пусто или ошибка загрузки → fallback на градиент + `coverLabel`

Обработка реализована в одном компоненте `app/lib/shared/widgets/book_cover_image.dart`.

**Клиентская модель BookModel также имеет вложенную модель `BookPart`** (добавлена в задаче 2.6) — соответствует `partSchema` на сервере. Поля: `number`, `title`, `duration`, `isPreviewAvailable`. Геттер `displayDuration` форматирует секунды → строку «45 мин» / «1 ч 15 мин».

**Почему MASTER не правится:** объёмный документ (~140 КБ), риск потерять контекст решений. Синхронизация MASTER с моделью — отдельная задача, когда будет время.
