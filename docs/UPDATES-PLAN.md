## 0. Что уже есть в коде

**Можно переиспользовать:**
- **Жалобы и блокировка.** Модель `Report` (`targetType: message | user | ai_analysis`, причины spam/inappropriate/offensive/copyright/other), `POST /api/users/:id/report`, `POST/DELETE /api/users/:id/block`, `GET /api/users/blocked`, экран `blocked_users_screen.dart`. В админке вкладка «Модерация»: `GET /api/admin/reports`, `POST /api/admin/reports/:id/action` (hide_message / warn / mute / ban / dismiss). Чат фильтрует заблокированных (`club.js:100`). **Не покрывает:** фото ленты, отзывы, профили — для них новые `targetType` и действия (блок A).
- **Роль Анны.** `User.role = 'admin'`, в клубе это `ClubAccessKind.admin`. По ней уже работают бейдж «Автор клуба», ответы в Q&A, упоминания (`sanitizeMentions` пускает только админов). Вкладку «Вопросы мне» вешаем на ту же роль.
- **Чат.** `ChatMessage`: типы text/image/voice, `replyToId`, реакции (6 эмодзи), `mentions`, `isPinned`, `isHidden`, `reportCount`; сокеты `chat:*`. «Вопрос Анне» — это сообщение чата с флагом, а не отдельная сущность.
- **Q&A.** `QAQuestion` + вкладка `qa_tab.dart` (567 строк) + `ask_question_sheet.dart` + админские `GET /api/admin/qa/unanswered`, `POST /api/admin/qa/:id/answer` + раздел в `server/admin/index.html`. По решению вкладка убирается; шторку вопроса можно переиспользовать.
- **Загрузка фото.** `image.service.js`: приём через multer, лимит 8 МБ, HEIC → JPEG, раздача по подписанной ссылке с фиксированным сроком (кэшируется). Клиент сжимает до 2000 px, качество 85 (`chat_tab.dart`, `image_picker`). Кадрирование — `image_cropper` (аватар). Ресайза на сервере нет.
- **Прослушивание.** `POST /api/progress` считает `secondsDelta` — только **новую** пройденную часть (повторное прослушивание и перемотка назад не считаются), копит в `Progress.totalListenedSeconds`. По дням ничего не хранится.
- **Серия сейчас.** Только в дневнике: `calculateDiaryStats` на клиенте, «дни подряд с цитатами» (`diary_provider.dart:97`). Сервер серий не знает.
- **Пуши.** `push.service.js`: `sendToUser`, `broadcast`, `sendNews`; настройки `User.pushSettings` (dailyQuote, newAudio, aiReady, chatMessages, reports, news, reminders); лента `Notification`. Ежедневное напоминание — cron в `push-scheduler.js` (время и текст из админки). Админский пуш `POST /api/admin/push/send`: аудитория me/all/subscribers, `data.type = 'admin'` → тап ведёт на Главную. Маршрутизация тапа — `push_service.dart` (`ai_ready`, `weekly_report`, `chat_reply`, `mention`, `qa_answer` …).
- **Книга.** `Book.rating`, `Book.reviewCount` в схеме есть, на экране книги рейтинг показывается при `rating > 0` (`book_screen.dart:333`). Отзывов как сущности нет.
- **Клуб.** `ClubMonth.participantCount` в схеме есть, но **не обновляется** (пишут только seed-скрипты). Доступ — `clubMonthsEntitled` + `computeClubAccess`.
- **Сетевые ошибки.** `isConnectionError()` в `core/network/network_error.dart` уже отличает обрыв сети от ответа сервера; в чате им не пользуются. Строк «Не удалось …» в клиенте — 69.

**Нет совсем:**
- поле «о себе» у пользователя, публичный профиль, чужой профиль;
- друзья/подписки;
- полка;
- лента фото и истории;
- отзывы;
- серверная серия, дневной лог активности, заморозки;
- виджет (нет `home_widget`, нет iOS Widget Extension, нет Android AppWidget);
- публичность цитат (`Quote` — только личные).

**Навигация сейчас:** 4 вкладки — Главная / Каталог / Клуб / Профиль (`app_bottom_bar.dart`). Дневник открывается из Профиля («Мой дневник»). Главная: шапка → карточка клуба месяца → баннер сезона → мысль дня → бесплатные → «продолжить» → популярное (`home_screen.dart:66-113`). Клуб: вкладки Разборы / Чат / Q&A (`club_screen.dart:242`). Пятую вкладку не добавляем.

## 1. Правила, которые касаются всех задач

| # | Правило | Что делать |
|---|---|---|
| P1 | **UGC (Apple 1.2, Google UGC policy):** на любом пользовательском контенте — жалоба, блокировка автора, скрытие модератором, контакт поддержки | новые типы контента (фото, отзыв, профиль) — сразу с кнопкой «Пожаловаться» и фильтром заблокированных; модерация постфактум в админке (блок A) |
| P2 | **Удаление аккаунта** должно удалять и новый контент | расширить удаление: посты, фото с диска, отзывы, полка, дружбы, активность (A4) |
| P3 | **Privacy labels / Data safety:** фото и тексты становятся публичными | обновить анкеты в ASC и Play Console перед релизом с лентой (A5) |
| P4 | **Android бесплатный** (`kPurchasesEnabled` в ветке `android` — функция `defaultTargetPlatform != android`) | всё, что ведёт к покупке, на Android ведёт к превью/«Для участниц», без цен (K) |
| P5 | **Ветки.** Сервер — из `main`. Клиент: общие правки пишутся в `main`, затем `main → android` (merge). Только-Android (Android-виджет, ветвления по `kPurchasesEnabled`) — в `android` | каждую задачу клиента проверять на обеих платформах; `store_policy.dart` в `main` пока нет — если общему коду нужен флаг, перенести файл в `main` (на iOS он всегда `true`) |
| P6 | **Модерация постфактум** — публикуется сразу | никакой премодерации; скрыть может Анна (роль admin) и модератор в админке |
| P7 | **Сервер не ломать старым клиентам** | новые поля опциональные, старые эндпоинты Q&A живут, пока в сторе есть сборка с вкладкой Q&A |

### D. Вопросы Анне — раздел «Вопросы» в клубе (3 дня)

Решение (23.10, уточнено Анной 26–27.10): **третий раздел клуба остаётся**, называется «Вопросы» (вместо Q&A). Участница задаёт **до 3 вопросов в неделю**. Все участницы клуба видят вопросы месяца и жмут «тоже интересно». У Анны самые популярные сверху. Анна **индивидуально не отвечает** — собирает вопросы в подкаст/эфир; при желании может ответить текстом. Задать вопрос можно и из чата кнопкой «Вопрос Анне» — открывает ту же шторку, вопрос попадает в раздел. Строим на существующих `QAQuestion` + `qa_tab.dart` + `ask_question_sheet.dart`, а не на сообщениях чата.

- [ ] D1. `QAQuestion` += `interestedUserIds: [ObjectId]`, `status: 'open'|'podcast'|'answered'` (по умолчанию `open`; `answerText`, `answeredAt` уже есть). Индексы `{clubMonthId, status, createdAt}`.
  Файл: `server/src/models/QAQuestion.js`.
- [ ] D2. Отправка: существующий роут создания вопроса → лимит **3 в неделю** на пользователя в клубе (неделя пн–вс по Москве, как cron) → `429 QUESTION_LIMIT` «На этой неделе можно задать ещё 0 вопросов». Админ не ограничен.

- [ ] D3. «Тоже интересно»: `POST /api/club/qa/:questionId/interest` (toggle, атомарно `$addToSet`/`$pull`), сокет `qa:updated` с числом. Права — доступ к клубу.

Клиент, участницы: `qa_tab.dart` → переименовать в «Вопросы», карточка вопроса с «Тоже интересно · N» и статусом («Будет в подкасте» / «Анна ответила»), кнопка «Задать вопрос» с остатком «осталось 2 из 3 на этой неделе». В `chat_input.dart` кнопка «Вопрос Анне» открывает `ask_question_sheet.dart`.
  ⚠️ `qa_tab.dart` и `club_screen.dart` в `android` изменены (5 и 14 строк) — merge вручную.
- [ ] D8. Клиент, Анна (`ClubAccessKind.admin`): та же вкладка с сортировкой «Популярные / Новые», фильтр по статусу, кнопки «В подкаст» и «Ответить».

## 5. Риски и неизвестное

- **Виджет — нативный код.** iOS Widget Extension требует второго bundle id, App Group и подписи второго таргета в Codemagic (аккаунт Individual, подпись только через Codemagic — см. AI-CONTEXT). Android-виджет — отдельно в ветке `android`. Самая неопределённая часть оценки.
- **Дневной лог прослушивания.** Сейчас считается только новая пройденная часть; честные «10 минут в день» требуют нового счётчика с клиента (I2) и защиты от накрутки (не больше реального времени между сохранениями).
- **Ревью Apple с новым UGC.** Лента фото, профили и отзывы — новый пользовательский контент; Apple может запросить демонстрацию жалоб/блокировки/модерации или задержать релиз. Демо-аккаунт ревьюера (`appreview@`, `appreview2@`) должен видеть ленту и иметь чужие посты.
- **Нагрузка на сервер и диск.** Фото раздаются через Node, ресайза на сервере нет, хранилище — диск VPS (общий с другим проектом). Нужны лимиты постов, превью-размер (H3) и контроль места на диске.
- **Merge `main` → `android`.** Файлы, которые меняют и доработки, и Android-ветка: `book_screen.dart`, `club_screen.dart`, `qa_tab.dart`, `home_screen.dart`, `quote_sheet.dart`, `app_router.dart`, `push_service.dart`, `player_screen.dart`. Мёрджить после каждого релиза, не копить.
- **Сервер в `android` отстаёт от `main`.** Сервер деплоится только из `main`; серверные части задач — только в `main`.
- **Часовые пояса** для серии (участницы в разных странах) — сутки считать по поясу пользователя, cron — по каждому поясу.
- **Старые сборки** с вкладкой Q&A живут у тех, кто не обновился — эндпоинты Q&A не удалять (P7).
