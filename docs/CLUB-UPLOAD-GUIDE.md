# ЧИТАТЕЛЬ — как загрузить клуб месяца через админку

Инструкция для помощницы Анны. Один клуб = один месяц = один эксклюзивный разбор.
Клуб открывается 1-го числа и закрывается в последний день месяца автоматически —
по датам, руками ничего включать не нужно. Загружать клуб надо **заранее**, лучше
за несколько дней до 1-го числа: если 1-го числа клуба нет, у всех подписчиц во
вкладке «Клуб» будет ошибка «Не удалось загрузить клуб».

## Что подготовить до начала

- Название книги и автор.
- Описание клуба (текст, до 5000 знаков). Показывается во вкладке «О клубе» и на
  экране разбора.
- Обложка: jpg / png / webp / heic, до 8 МБ, вертикальная 2:3 (лучше 600×900).
- Аудио: mp3 / m4a / aac / wav. Приветствие Анны — отдельным файлом, дальше части
  разбора отдельными файлами, в порядке прослушивания.
- Названия частей. В приложении части подписаны по номерам («Часть 1», «Часть 2»…),
  под номером — ваше название. Первой частью всегда идёт приветствие:
  номер 1 — «Приветствие»; дальше номер 2 — «Часть 1», номер 3 — «Часть 2» и т.д.
  (окончательные названия частей решим позже).

## Пошагово

1. Откройте админку, войдите под аккаунтом с ролью администратора.
2. Вкладка **«Клуб месяца»** → кнопка **«+ Новый клуб месяца»**.
3. **1. Месяц клуба** — выберите месяц (например, октябрь 2026).
4. Нажмите **«＋ Создать разбор для клуба»**. Откроется редактор разбора — он уже
   помечен клубным: в общий каталог не попадёт и отдельно продаваться не будет.
   Полей «цена» и «тип» у него нет — так и должно быть, доступ даёт подписка.
5. Заполните **Название**, **Автор книги**, **Описание** → **«Сохранить»**.
   После сохранения появятся блоки обложки и аудио.
6. **Обложка**: выберите файл → **«Загрузить обложку»**. Картинка появится над кнопкой.
7. **Аудио-части**, по одной:
   - Номер части: 1, Название: «Приветствие», файл приветствия →
     **«Загрузить часть»**.
   - Номер части: 2, Название: «Часть 1», файл → «Загрузить часть»; номер 3 —
     «Часть 2» и т.д.
   - И так далее. Длительность считается сама. Если ошиблись файлом — загрузите
     ещё раз с тем же номером, часть заменится. Крестик рядом с частью удаляет её.
8. Когда все части на месте — **«Опубликовать»**. Без публикации разбор в
   приложении не откроется (в форме клуба будет пометка «черновик — опубликуйте»).
9. Нажмите **«К клубу месяца →»** (кнопка в редакторе разбора). Откроется форма клуба
   с выбранным месяцем и этим разбором. Проверьте месяц и превью разбора (обложка,
   число частей, нет пометок «нет аудио» / «черновик») → **«Создать клуб»**.
10. Клуб появился в списке «Клуб месяца». 1-го числа он откроется у подписчиц сам.

## Проверка в приложении

В день открытия: вкладка «Клуб» → шапка «Клуб <месяц>» с названием книги →
вкладка «О клубе»: обложка, описание, кнопка «Слушать разбор» → открывается список
частей, первая — приветствие. У администратора всё это видно и до 1-го числа
(через переключатель клубов в шапке — будущие клубы админу показываются).

## Если что-то пошло не так

- **«Этот разбор из общего каталога…»** при сохранении клуба — выбран обычный
  разбор из каталога. К клубу можно привязать только разбор, созданный кнопкой
  «Создать разбор для клуба». Создайте его по шагам 4–8.
- **«Клуб на 2026-10 уже существует»** — на этот месяц клуб уже заведён; откройте
  его из списка и отредактируйте, а не создавайте второй.
- **«Опубликовать» выдаёт ошибку** — у разбора нет ни одной аудио-части.
  Загрузите хотя бы одну и повторите.
- **Пометка «нет аудио»** в превью клуба — части не загружены (шаг 7).
- **Нужно поменять текст, обложку или часть уже после создания клуба** — вкладка
  «Каталог» → найдите разбор (бейдж «клуб») → откройте → правьте → «Сохранить».
  Клуб перезаводить не нужно.

## Чего делать не нужно

- Не создавайте клубный разбор через «Каталог → + Новый разбор» — так он попадёт в
  общий каталог как платный товар. Только через кнопку в форме клуба.
- Не выбирайте в форме клуба чужой разбор из каталога (их там и нет — но на всякий
  случай).
- Не удаляйте клуб после его открытия: пропадёт чат участниц за месяц.
- Не ставьте «Опубликовать» разбору без приветствия/частей «на потом» — подписчицы
  увидят пустой список.

## Что можно сделать только из приложения (не из админки)

- Голосовое сообщение в чат клуба — записывается вживую из приложения Анной, до
  3 минут. Файлом через админку не загружается. Поэтому аудио-приветствие идёт
  частью 1 разбора.
- Закрепить сообщение в чате — долгое нажатие на сообщение → «Закрепить».
