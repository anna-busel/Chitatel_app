### Принятые решения (спека противоречила себе — зафиксировано)
1. **Поля разбора — как в промпте:** `aiAnalysis { resonance, context, question, createdAt }`. В MASTER 7.3 стояли старые имена (text/pattern) — они не совпадали с JSON промпта из MASTER 7.7. Экран 4.25: resonance → «Что эта цитата говорит о вас», context → «Паттерн».
2. **Добавлено поле `aiStatus`** (skipped/pending/ready/failed) — в схеме MASTER его не было, но без него не работают коды `AI_ANALYSIS_PENDING/FAILED`.
3. **Отчёт:** `aiSummary { weekTheme, insight, recommendation { title, author, why, bookId } }` — как в промпте (в MASTER 7.3 recommendation была строкой).
4. **Порог отчёта — 3 цитаты/неделю** (STEP-BY-STEP; в MASTER 7.7 стояло ≥1). Риск: у новичков отчёт может не приходить вовсе — вернуться к вопросу после первых живых юзеров.
5. **Очереди нет** (Bull требует Redis, его на VPS нет): анализ запускается сразу после POST /api/quotes через `setImmediate`, цитата отдаётся со статусом `pending`.
6. **Рекомендация — только реальная книга:** в промпт подставляется список опубликованных разборов (`isPublished:true`), ответ модели сверяется с базой → `bookId`. Не опознал — блок рекомендации в отчёте не показывается. Кнопка «Открыть разбор» → экран книги (там «Слушать»/«Купить»/«Продолжить»; покупка только через IAP). ⚠️ Пока почти весь каталог `isPublished:false` (нет аудио) → рекомендация будет пустой. Само оживёт по мере публикации.
7. **Push «анализ готов» НЕ делали** — push-сервиса ещё нет (задача 6.1).
8. **FAB-перо — только главная + дневник.** Прототип v4.2 рисовал его на всех экранах (`FAB_SCREENS`), но в клубе он садится поверх ленты чата и кнопки «вниз», в каталоге/профиле цитате взяться неоткуда. Правило: **перо там, где есть текст, который может зацепить.** Решение юзера.
9. **Минуты прослушивания в отчёте = 0** — Progress хранит только суммарное время без разбивки по дням. Недельная статистика — задача 6.2 (`GET /api/progress/stats`).

**#56 ⚠️ СПЕКА ПРОТИВОРЕЧИТ САМА СЕБЕ — ФИКСИРУЙ ВЫБОР, А НЕ УГАДЫВАЙ (12.07, Фаза 5).** MASTER 7.3 (схема Quote/WeeklyReport) расходился с MASTER 7.7 (JSON промптов): text/pattern против resonance/context, recommendation строкой против объекта; порог отчёта ≥1 (MASTER) против ≥3 (STEP-BY-STEP); поля aiStatus в схеме не было вовсе, хотя коды ошибок его требуют.
