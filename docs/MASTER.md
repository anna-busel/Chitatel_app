## 1. ПРОДУКТ

### Что это
ЧИТАТЕЛЬ — мобильное приложение книжного клуба психолога Анны Бусел. Пользователи слушают аудиоразборы книг (голосом Анны), сохраняют цитаты, получают ИИ-анализ своих цитат и общаются в закрытом чате.

### Для кого
Женщины 25–45, интересующиеся психологией и литературой. Русскоязычная аудитория. Основной рынок — Россия, СНГ, русскоязычная диаспора.

### Как зарабатывает

**Подписки (Auto-Renewable, через Apple IAP):**

| Тариф | Что входит | Длительности |
|-------|-----------|-------------|
| Базовый | Аудиоразборы, чат, дневник, ИИ-анализ | 1 / 6 / 12 месяцев |
| Премиум | Всё из базового + Zoom-встречи с Анной | 1 / 6 / 12 месяцев |

**Разовые покупки (Non-Consumable, через Apple IAP):**
- Отдельный аудиоразбор книги — доступ навсегда
- Пакет из 5 книг — со скидкой, доступ навсегда
- Вечный доступ к архиву — все существующие записи навсегда (без чата, Zoom, новых разборов)

**Важно:** Zoom-встречи групповые (Анна + участницы) — Apple требует оплату через IAP. Это не наш выбор, а правило Apple (Guideline 3.1.3(d)).

### Бесплатный контент
Часть разборов доступна бесплатно (без регистрации и оплаты). Это воронка привлечения.

### Технологии
- **Фронтенд:** Flutter (iOS + Android из одной кодовой базы)
- **Бэкенд:** Node.js + Express + JavaScript (ES2020+) + MongoDB на Contabo VPS
- **Веб-сервер:** nginx (reverse proxy, раздача аудио, signed URLs)
- **Оплата:** Apple In-App Purchase (StoreKit 2) для iOS, Google Play Billing для Android
- **ИИ-анализ:** OpenAI API (GPT-4o-mini)
- **Аудио:** стриминг через nginx с VPS, Cloudflare CDN опционально
- **Реал-тайм:** Socket.io (чат клуба)
- **Push:** APNs (iOS), FCM (Android)

## 2. ПОЛЬЗОВАТЕЛИ И СОСТОЯНИЯ

### Типы пользователей

| Тип | Описание | Что видит |
|-----|----------|-----------|
| **Гость** | Не зарегистрирован. Нажал «Пропустить» на экране входа | Бесплатные разборы, каталог, превью платных. Не видит клуб, чат, дневник |
| **Бесплатный** | Зарегистрирован, но без подписки | Всё что гость + дневник, цитаты, профиль. Клуб показывает предложение подписки |
| **Базовый подписчик** | Оплатил базовую подписку | Полный доступ: клуб, чат, Q&A, аудиоразборы месяца. Без Zoom |
| **Премиум подписчик** | Оплатил премиум подписку | Всё из базового + Zoom-встречи с Анной |
| **Бывший подписчик** | Подписка истекла | Как бесплатный + купленные разборы сохраняются навсегда. 3 дня доступа к записям клуба после отмены |
| **Владелец архива** | Купил «Вечный доступ к архиву» | Все существующие записи навсегда. Без чата, Zoom, новых разборов (если нет активной подписки) |

### Состояния контента

| Состояние | Иконка/бейдж | Что пользователь может |
|-----------|-------------|----------------------|
| Бесплатно | Зелёный бейдж «БЕСПЛАТНО» | Слушать полностью |
| Платный | Цена красным ($12) | Слушать превью 5 мин, купить |
| Куплено | Синий бейдж «КУПЛЕНО» | Слушать полностью, прогресс сохраняется |
| Подписка | Нет бейджа, доступ через клуб | Слушать пока подписка активна |
| Заблокировано | Замок | Не может слушать (часть платного разбора) |

## 3. СЦЕНАРИИ

### 3.1. Новый пользователь → первое прослушивание

```
Открывает приложение
  → Онбординг (3 слайда: слушай, записывай, анализируй)
  → Экран входа (Apple / Google / Email / Пропустить)
  
  Если «Пропустить»:
    → Попадает на главную как гость
    → Видит бесплатные разборы
    → Нажимает на «Маленький принц»
    → Экран книги → «Слушать бесплатно»
    → Плеер запускается
    
  Если регистрируется:
    → Опрос (7 вопросов для персонализации)
    → Согласие на ИИ-анализ (да / пока без)
    → Разрешение push-уведомлений (разрешить / не сейчас)
    → Попадает на главную
```

### 3.2. Бесплатный → подписчик

```
Пользователь на главной
  → Видит карточку «Клуб марта — Бегство от свободы»
  → Нажимает → переход на экран тарифов
  → Выбирает тариф:
    - Базовый (1 мес / 6 мес / год)
    - Премиум (1 мес / 6 мес / год)
  → Нажимает «Подписаться»
  → Системный диалог Apple Pay
  → Если успешно → экран «Добро пожаловать в клуб!»
  → Кнопка «Начать слушать» → попадает в клуб
```

### 3.3. Подписчик слушает разбор

```
Переходит во вкладку «Клуб»
  → Видит текущий клуб месяца, прогресс, расписание
  → Вкладка «Разборы» → список из 4 частей
  → Нажимает на доступную часть → плеер
  → Во время прослушивания может:
    - Изменить скорость (0.75× / 1.0× / 1.25× / 1.5× / 2.0×)
    - Сохранить цитату (кнопка «Цитата» или FAB)
    - Поставить таймер сна (15 / 30 / 45 / 60 мин / конец части)
    - Перемотать ±15 секунд
  → Свернуть плеер → мини-плеер внизу экрана
  → Может продолжать навигацию по приложению
```

### 3.4. Сохранение цитаты → ИИ-анализ

```
Пользователь слушает разбор (или просто в приложении)
  → Нажимает FAB (перо) или кнопку «Цитата» в плеере
  → Открывается шторка «Новая цитата»
  → Если плеер активен — автор и книга подставляются автоматически
  → Вводит текст цитаты
  → Нажимает «Сохранить»
  
  Если ИИ-анализ включён:
    → Цитата отправляется в OpenAI
    → Через ~10 сек в дневнике появляется «Анализ от Анны →»
    → Нажимает → экран анализа (что цитата говорит о вас, паттерн, вопрос)
    
  Если ИИ-анализ не включён:
    → Появляется модальное окно «Включить ИИ-анализ?»
    → Да → включается, цитата анализируется
    → Нет → цитата просто сохраняется в дневнике
```

### 3.5. Общение в чате клуба

```
Вкладка «Клуб» → таб «Чат»
  → Видит закреплённое сообщение Анны
  → Видит сообщения участниц
  → Может написать сообщение (поле ввода внизу)
  → Может прикрепить фото
  → Может ответить на чужое сообщение (нажатие → меню → «Ответить»)
  → Может пожаловаться (меню → «Пожаловаться» → выбор причины)
  → Может заблокировать пользователя
```

### 3.6. Подписка истекла

```
Подписка не продлилась
  → При входе в приложение → экран «Подписка истекла»
  → Объясняет: подписочный контент закроется через 3 дня
  → Купленные разборы остаются навсегда
  → Две кнопки: «Продлить подписку» и «Купить записи»
  → «Восстановить покупки» — если оплата прошла но не отразилась
```

### 3.7. Удаление аккаунта

```
Профиль → «Удалить аккаунт»
  → Экран с предупреждениями:
    - Данные удаляются в течение 24 часов
    - Цитаты, прогресс, анализы — безвозвратно
    - Купленные разборы станут недоступны
    - Подписки НЕ отменяются автоматически
  → Нужно ввести «УДАЛИТЬ» для подтверждения
  → Кнопка «Удалить аккаунт навсегда»
  → Или «Отмена» — назад в профиль
```

### 3.8. Покупка отдельного разбора

```
Каталог → нажимает на платную книгу
  → Экран книги: описание, содержание, отзывы
  → Часть 1 открыта для превью (5 мин)
  → Кнопка «Купить за $12»
  → Системный диалог оплаты
  → Если успешно → книга отмечается «КУПЛЕНО»
  → Все 4 части разблокированы навсегда
```

### 3.9. Покупка пакета

```
Каталог → баннер «Пакет Отношения — 5 книг»
  → Экран пакета: список книг, цена, скидка
  → «Купить пакет — $25» (вместо $42 по отдельности)
  → Оплата → все 5 книг разблокированы
```

### 3.10. Нет интернета

```
Приложение не может загрузить данные
  → Экран «Нет подключения»
  → «Проверьте интернет-соединение и попробуйте снова»
  → Кнопка «Попробовать снова»
```

### 3.11. Приглашение подруги (реферал)

```
Главная → баннер «Подарите подруге»
  → Экран реферала
  → Уникальная ссылка: chitatel.app/ref/anna2026
  → «Скопировать ссылку» или «Поделиться в мессенджере»
  → Статистика: сколько приглашено, сколько вступили, сколько бонусов
  → Бонус: бесплатный разбор за каждую приглашённую подругу
```

### 3.12. Покупка вечного доступа к архиву

```
Каталог → баннер «Вечный доступ к архиву»
  → Экран: описание, что входит (все записанные разборы)
  → Чётко указано: без чата, без Zoom, без новых разборов
  → Кнопка «Купить навсегда — $XX»
  → Оплата → все архивные разборы разблокированы навсегда
```

## 4. ЭКРАНЫ

Всего: 35 экранов + 4 модальных окна + 3 шторки (bottom sheet).

### Условные обозначения
- 🆓 — доступен без регистрации
- 🔐 — нужна регистрация
- 💎 — нужна подписка
- 📱 — модальное окно / шторка

---

### 4.1. Онбординг 🆓

**Путь:** первый запуск приложения

**Что на экране:**
- 3 слайда, переключаются свайпом или кнопкой «Далее»
- Слайд 1: «Слушайте. Аудиоразборы книг от психолога» + иконка наушников
- Слайд 2: «Записывайте. Сохраняйте цитаты в личный дневник» + иконка пера
- Слайд 3: «Анализируйте. ИИ найдёт паттерны в ваших мыслях» + иконка искры
- Точки-индикатор внизу (какой слайд активен)
- На 3-м слайде кнопка «Начать»

**Действия:**
- Свайп / «Далее» → следующий слайд
- «Начать» → экран входа

---

### 4.2. Экран входа 🆓

**Путь:** после онбординга

**Что на экране:**
- Логотип ЧИТАТЕЛЬ (Playfair Display, с засечками)
- Подпись «Книжный клуб Анны Бусел»
- 3 кнопки входа:
  - «Войти с Apple» (чёрная) — **обязательно первая, Apple требует**
  - «Войти с Google» (белая с рамкой)
  - «Email и пароль» (серая)
- Чекбокс GDPR: «Я согласна на обработку данных и принимаю Условия и Политику конфиденциальности»
  - Кнопки неактивны (прозрачные 40%) пока чекбокс не нажат
- Ссылка «Забыли пароль?»
- Ссылка «Пропустить» — позволяет войти без регистрации

**Действия:**
- Apple/Google/Email → соответствующий процесс авторизации
- «Пропустить» → главная (режим гостя)

### 4.6. Опрос (7 шагов) 🔐

**Путь:** после регистрации

**Что на экране:**
- Прогресс-бар «Персонализация · X/7»
- Вопрос (крупный, с засечками)
- Подсказка (если есть)
- Варианты ответов — карточки с иконками
- Кнопка «Далее» (на 7-м шаге — «Завершить»)
- Ссылка «Пропустить» — перескочить опрос

**Вопросы:**
1. Что вас привело в книжный клуб? (Саморазвитие / Отношения / Любовь к литературе / Подруга посоветовала)
2. Сколько книг вы читаете в месяц? (0–1 / 2–3 / 4+)
3. Что вам интереснее? (Классика / Психология / И то, и другое)
4. Что вы хотите изменить? (Понять себя / Научиться диалогу / Меньше в телефоне / Больше дисциплины)
5. Как предпочитаете учиться? (Слушать / Читать и записывать / Обсуждать)
6. Когда удобнее слушать? (Утром 7–10 / Днём 12–15 / Вечером 19–22)
7. Слушали разборы Анны раньше? (Да, в Instagram/YouTube / Нет, я новенькая / Была в Telegram-боте)

**Зачем:** персонализация контента, время push-уведомлений, понимание аудитории.

### 4.7. Согласие на ИИ 🔐

**Путь:** после опроса

**Что на экране:**
- Иконка искры (фиолетовая)
- Заголовок «ИИ-анализ ваших цитат»
- Объяснение: «Когда вы сохраняете цитату, наш ИИ подготовит персональный психологический анализ»
- Карточка с 6 пунктами:
  - Цитаты обрабатываются OpenAI API
  - Данные не используются для обучения моделей
  - Результаты хранятся на наших серверах

  - Анализ — это не терапия и не диагноз
  - Отключить можно в настройках
- Кнопка «Согласна, включить ИИ-анализ»
- Ссылка «Пока без ИИ»

### 4.9. Главная 🆓

**Путь:** таб «Главная» (первый)

**Что на экране:**

*Шапка:*
- Аватар пользователя (слева, нажатие → профиль)
- Логотип ЧИТАТЕЛЬ (по центру)
- Колокольчик уведомлений (справа, красная точка если есть новые)

*Контент (скролл):*
- **Клуб марта** — главная карточка. Тёмный фон, название книги, автор, кнопка «Вступить — $18/мес». Нажатие → экран тарифов.
- **Мысль дня** — цитата из текущей книги с кнопками «В дневник» / «Поделиться»
- **Бесплатные разборы** — горизонтальная лента карточек (3 книги). «Все →» → каталог.
- **Мой прогресс** — полоска прогресса к недельной цели. Для нового пользователя — «Начните слушать первый разбор».
- **Популярные разборы** (только для активных) — вертикальный список
- **Подарите подруге** — реферальный баннер

### 4.10. Каталог 🆓

**Путь:** таб «Каталог» (второй)

**Что на экране:**
- Поле поиска «Поиск по названию, автору...» (нажатие → полноэкранный поиск)
- Фильтры: Все / Классика / Психология / Пакеты / Бесплатные (горизонтальная лента)
- Баннер пакета «Пакет Отношения — 5 книг, −40%»
- Сетка книг (2 колонки): обложка-градиент, бейдж (бесплатно/куплено), название, автор, длительность, цена

**Действия:**
- Нажатие на книгу → экран книги (бесплатной, платной или купленной)
- Фильтр → показывает только соответствующие книги

### 4.11. Поиск 🆓

**Путь:** каталог → нажатие на строку поиска

**Что на экране:**
- Поле ввода с автофокусом

### 6.2.1. Качество кода — требования Apple (неявные)

Apple не проверяет исходный код, но отклоняет за РЕЗУЛЬТАТ плохого кода:

**Критичные (reject):**
- Crash при запуске, при навигации, при покупке — нулевая толерантность
- Placeholder-контент (Lorem ipsum, TODO, пустые экраны)
- «Web wrapper» — приложение не должно выглядеть как обёрнутый сайт
- Использование private APIs — гарантированный reject
- Устаревший Xcode SDK — может не пройти processing

**Важные для качества (снижают риск rejection):**
- **Быстрый старт:** холодный запуск < 3 секунд. Splash screen → данные
- **Обработка ошибок:** каждый HTTP-запрос имеет try/catch, показывает осмысленную ошибку
- **Оффлайн:** приложение не падает без сети, показывает экран 4.38
- **Memory:** нет утечек памяти, особенно в плеере и чате (долгие сессии)
- **Нативный вид:** используем стандартные iOS-паттерны (swipe back, pull to refresh, sheet dismissal)

**Наши правила для чистого кода (экономия токенов при AI-разработке):**
- Один файл = одна ответственность (SRP)
- Нет дублирования: общие виджеты в `shared/widgets/`, общие сервисы в `core/`
- Все строки UI — в одном месте (для будущей локализации)
- Все цвета/шрифты — ТОЛЬКО из дизайн-системы, никогда хардкод
- Zod-валидация на каждом эндпоинте — не доверяем входным данным
- Riverpod на Flutter — предсказуемый state management, нет widget rebuild hell
- Именование: `feature_name/screens/`, `feature_name/providers/`, `feature_name/widgets/`
