## 1. ПРОДУКТ

### Что это
ЧИТАТЕЛЬ — мобильное приложение книжного клуба психолога Анны Бусел. Пользователи слушают аудиоразборы книг (голосом Анны), сохраняют цитаты, получают ИИ-анализ своих цитат и общаются в закрытом чате.

### Для кого
Женщины 25–45, интересующиеся психологией и литературой. Русскоязычная аудитория. Основной рынок — Россия, СНГ, русскоязычная диаспора.

### Как зарабатывает

**Подписки (Auto-Renewable, через Apple IAP):**

| Тариф | Что входит | Длительности |
|-------|-----------|-------------|
| Базовый | Аудиоразборы, чат, дневник, ИИ-анализ | 1 / 6 / 12 месяцев |
| Премиум | Всё из базового + Zoom-встречи с Анной | 1 / 6 / 12 месяцев |

**Разовые покупки (Non-Consumable, через Apple IAP):**
- Отдельный аудиоразбор книги — доступ навсегда
- Пакет из 5 книг — со скидкой, доступ навсегда
- Вечный доступ к архиву — все существующие записи навсегда (без чата, Zoom, новых разборов)

**Важно:** Zoom-встречи групповые (Анна + участницы) — Apple требует оплату через IAP. Это не наш выбор, а правило Apple (Guideline 3.1.3(d)).

### Бесплатный контент
Часть разборов доступна бесплатно (без регистрации и оплаты). Это воронка привлечения.

### Технологии
- **Фронтенд:** Flutter (iOS + Android из одной кодовой базы)
- **Бэкенд:** Node.js + Express + JavaScript (ES2020+) + MongoDB на Contabo VPS
- **Веб-сервер:** nginx (reverse proxy, раздача аудио, signed URLs)
- **Оплата:** Apple In-App Purchase (StoreKit 2) для iOS, Google Play Billing для Android
- **ИИ-анализ:** OpenAI API (GPT-4o-mini)
- **Аудио:** стриминг через nginx с VPS, Cloudflare CDN опционально
- **Реал-тайм:** Socket.io (чат клуба)
- **Push:** APNs (iOS), FCM (Android)

## 2. ПОЛЬЗОВАТЕЛИ И СОСТОЯНИЯ

### Типы пользователей

| Тип | Описание | Что видит |
|-----|----------|-----------|
| **Гость** | Не зарегистрирован. Нажал «Пропустить» на экране входа | Бесплатные разборы, каталог, превью платных. Не видит клуб, чат, дневник |
| **Бесплатный** | Зарегистрирован, но без подписки | Всё что гость + дневник, цитаты, профиль. Клуб показывает предложение подписки |
| **Базовый подписчик** | Оплатил базовую подписку | Полный доступ: клуб, чат, Q&A, аудиоразборы месяца. Без Zoom |
| **Премиум подписчик** | Оплатил премиум подписку | Всё из базового + Zoom-встречи с Анной |
| **Бывший подписчик** | Подписка истекла | Как бесплатный + купленные разборы сохраняются навсегда. Записи клуба доступны всем участникам 15 дней после окончания месяца (независимо от статуса подписки) |
| **Владелец архива** | Купил «Вечный доступ к архиву» | Все существующие записи навсегда. Без чата, Zoom, новых разборов (если нет активной подписки) |

### Состояния контента

| Состояние | Иконка/бейдж | Что пользователь может |
|-----------|-------------|----------------------|
| Бесплатно | Зелёный бейдж «БЕСПЛАТНО» | Слушать полностью |
| Платный | Цена красным ($12) | Слушать превью 5 мин, купить |
| Куплено | Синий бейдж «КУПЛЕНО» | Слушать полностью, прогресс сохраняется |
| Подписка | Нет бейджа, доступ через клуб | Слушать пока подписка активна |
| Заблокировано | Замок | Не может слушать (часть платного разбора) |

## 3. СЦЕНАРИИ

### 3.1. Новый пользователь → первое прослушивание

```
Открывает приложение
  → Онбординг (3 слайда: слушай, записывай, анализируй)
  → Экран входа (Apple / Google / Email / Пропустить)
  
  Если «Пропустить»:
    → Попадает на главную как гость
    → Видит бесплатные разборы
    → Нажимает на «Маленький принц»
    → Экран книги → «Слушать бесплатно»
    → Плеер запускается
    
  Если регистрируется:
    → Опрос (7 вопросов для персонализации)
    → Согласие на ИИ-анализ (да / пока без)
    → Разрешение push-уведомлений (разрешить / не сейчас)
    → Попадает на главную
```

### 3.2. Бесплатный → подписчик

```
Пользователь на главной
  → Видит карточку «Клуб марта — Бегство от свободы»
  → Нажимает → переход на экран тарифов
  → Выбирает тариф:
    - Базовый (1 мес / 6 мес / год)
    - Премиум (1 мес / 6 мес / год)
  → Нажимает «Подписаться»
  → Системный диалог Apple Pay
  → Если успешно → экран «Добро пожаловать в клуб!»
  → Кнопка «Начать слушать» → попадает в клуб
```

### 3.3. Подписчик слушает разбор

```
Переходит во вкладку «Клуб»
  → Видит текущий клуб месяца, прогресс, расписание
  → Вкладка «Разборы» → список из 4 частей
  → Нажимает на доступную часть → плеер
  → Во время прослушивания может:
    - Изменить скорость (0.75× / 1.0× / 1.25× / 1.5× / 2.0×)
    - Сохранить цитату (кнопка «Цитата» или FAB)
    - Поставить таймер сна (15 / 30 / 45 / 60 мин / конец части)
    - Перемотать ±15 секунд
  → Свернуть плеер → мини-плеер внизу экрана
  → Может продолжать навигацию по приложению
```

### 3.4. Сохранение цитаты → ИИ-анализ

```
Пользователь слушает разбор (или просто в приложении)
  → Нажимает FAB (перо) или кнопку «Цитата» в плеере
  → Открывается шторка «Новая цитата»
  → Если плеер активен — автор и книга подставляются автоматически
  → Вводит текст цитаты
  → Нажимает «Сохранить»
  
  Если ИИ-анализ включён:
    → Цитата отправляется в OpenAI
    → Через ~10 сек в дневнике появляется «Анализ от Анны →»
    → Нажимает → экран анализа (что цитата говорит о вас, паттерн, вопрос)
    
  Если ИИ-анализ не включён:
    → Появляется модальное окно «Включить ИИ-анализ?»
    → Да → включается, цитата анализируется
    → Нет → цитата просто сохраняется в дневнике
```

### 3.5. Общение в чате клуба

```
Вкладка «Клуб» → таб «Чат»
  → Видит закреплённое сообщение Анны
  → Видит сообщения участниц
  → Может написать сообщение (поле ввода внизу)
  → Может прикрепить фото
  → Может ответить на чужое сообщение (нажатие → меню → «Ответить»)
  → Может пожаловаться (меню → «Пожаловаться» → выбор причины)
  → Может заблокировать пользователя
```

### 3.6. Подписка истекла

```
Подписка не продлилась
  → При входе в приложение → экран «Подписка истекла»
  → Объясняет: подписочный контент закроется через 3 дня
  → Купленные разборы остаются навсегда
  → Две кнопки: «Продлить подписку» и «Купить записи»
  → «Восстановить покупки» — если оплата прошла но не отразилась
```

### 3.7. Удаление аккаунта

```
Профиль → «Удалить аккаунт»
  → Экран с предупреждениями:
    - Данные удаляются в течение 24 часов
    - Цитаты, прогресс, анализы — безвозвратно
    - Купленные разборы станут недоступны
    - Подписки НЕ отменяются автоматически
  → Нужно ввести «УДАЛИТЬ» для подтверждения
  → Кнопка «Удалить аккаунт навсегда»
  → Или «Отмена» — назад в профиль
```

### 3.8. Покупка отдельного разбора

```
Каталог → нажимает на платную книгу
  → Экран книги: описание, содержание, отзывы
  → Часть 1 открыта для превью (5 мин)
  → Кнопка «Купить за $12»
  → Системный диалог оплаты
  → Если успешно → книга отмечается «КУПЛЕНО»
  → Все 4 части разблокированы навсегда
```

### 3.9. Покупка пакета

```
Каталог → баннер «Пакет Отношения — 5 книг»
  → Экран пакета: список книг, цена, скидка
  → «Купить пакет — $25» (вместо $42 по отдельности)
  → Оплата → все 5 книг разблокированы
```

### 3.10. Нет интернета

```
Приложение не может загрузить данные
  → Экран «Нет подключения»
  → «Проверьте интернет-соединение и попробуйте снова»
  → Кнопка «Попробовать снова»
```

### 3.11. Приглашение подруги (реферал)

```
Главная → баннер «Подарите подруге»
  → Экран реферала
  → Уникальная ссылка: chitatel.app/ref/anna2026
  → «Скопировать ссылку» или «Поделиться в мессенджере»
  → Статистика: сколько приглашено, сколько вступили, сколько бонусов
  → Бонус: бесплатный разбор за каждую приглашённую подругу
```

### 3.12. Покупка вечного доступа к архиву

```
Каталог → баннер «Вечный доступ к архиву»
  → Экран: описание, что входит (все записанные разборы)
  → Чётко указано: без чата, без Zoom, без новых разборов
  → Кнопка «Купить навсегда — $XX»
  → Оплата → все архивные разборы разблокированы навсегда
```

## 4. ЭКРАНЫ

Всего: 35 экранов + 4 модальных окна + 3 шторки (bottom sheet).

### Условные обозначения
- 🆓 — доступен без регистрации
- 🔐 — нужна регистрация
- 💎 — нужна подписка
- 📱 — модальное окно / шторка

---

### 4.1. Онбординг 🆓

**Путь:** первый запуск приложения

**Что на экране:**
- 3 слайда, переключаются свайпом или кнопкой «Далее»
- Слайд 1: «Слушайте. Аудиоразборы книг от психолога» + иконка наушников
- Слайд 2: «Записывайте. Сохраняйте цитаты в личный дневник» + иконка пера
- Слайд 3: «Анализируйте. ИИ найдёт паттерны в ваших мыслях» + иконка искры
- Точки-индикатор внизу (какой слайд активен)
- На 3-м слайде кнопка «Начать»

**Действия:**
- Свайп / «Далее» → следующий слайд
- «Начать» → экран входа

---

### 4.2. Экран входа 🆓

**Путь:** после онбординга

**Что на экране:**
- Логотип ЧИТАТЕЛЬ (Playfair Display, с засечками)
- Подпись «Книжный клуб Анны Бусел»
- 3 кнопки входа:
  - «Войти с Apple» (чёрная) — **обязательно первая, Apple требует**
  - «Войти с Google» (белая с рамкой)
  - «Email и пароль» (серая)
- Чекбокс GDPR: «Я согласна на обработку данных и принимаю Условия и Политику конфиденциальности»
  - Кнопки неактивны (прозрачные 40%) пока чекбокс не нажат
- Ссылка «Забыли пароль?»
- Ссылка «Пропустить» — позволяет войти без регистрации

**Действия:**
- Apple/Google/Email → соответствующий процесс авторизации
- «Пропустить» → главная (режим гостя)

### 4.6. Опрос (7 шагов) 🔐

**Путь:** после регистрации

**Что на экране:**
- Прогресс-бар «Персонализация · X/7»
- Вопрос (крупный, с засечками)
- Подсказка (если есть)
- Варианты ответов — карточки с иконками
- Кнопка «Далее» (на 7-м шаге — «Завершить»)
- Ссылка «Пропустить» — перескочить опрос

**Вопросы:**
1. Что вас привело в книжный клуб? (Саморазвитие / Отношения / Любовь к литературе / Подруга посоветовала)
2. Сколько книг вы читаете в месяц? (0–1 / 2–3 / 4+)
3. Что вам интереснее? (Классика / Психология / И то, и другое)
4. Что вы хотите изменить? (Понять себя / Научиться диалогу / Меньше в телефоне / Больше дисциплины)
5. Как предпочитаете учиться? (Слушать / Читать и записывать / Обсуждать)
6. Когда удобнее слушать? (Утром 7–10 / Днём 12–15 / Вечером 19–22)
7. Слушали разборы Анны раньше? (Да, в Instagram/YouTube / Нет, я новенькая / Была в Telegram-боте)

**Зачем:** персонализация контента, время push-уведомлений, понимание аудитории.

### 4.7. Согласие на ИИ 🔐

**Путь:** после опроса

**Что на экране:**
- Иконка искры (фиолетовая)
- Заголовок «ИИ-анализ ваших цитат»
- Объяснение: «Когда вы сохраняете цитату, наш ИИ подготовит персональный психологический анализ»
- Карточка с 6 пунктами:
  - Цитаты обрабатываются OpenAI API
  - Данные не используются для обучения моделей
  - Результаты хранятся на наших серверах
  - Удаляются вместе с аккаунтом или по запросу
  - Анализ — это не терапия и не диагноз
  - Отключить можно в настройках
- Кнопка «Согласна, включить ИИ-анализ»
- Ссылка «Пока без ИИ»

### 4.9. Главная 🆓

**Путь:** таб «Главная» (первый)

**Что на экране:**

*Шапка:*
- Аватар пользователя (слева, нажатие → профиль)
- Логотип ЧИТАТЕЛЬ (по центру)
- Колокольчик уведомлений (справа, красная точка если есть новые)

*Контент (скролл):*
- **Клуб марта** — главная карточка. Тёмный фон, название книги, автор, кнопка «Вступить — $18/мес». Нажатие → экран тарифов.
- **Мысль дня** — цитата из текущей книги с кнопками «В дневник» / «Поделиться»
- **Бесплатные разборы** — горизонтальная лента карточек (3 книги). «Все →» → каталог.
- **Мой прогресс** — полоска прогресса к недельной цели. Для нового пользователя — «Начните слушать первый разбор».
- **Популярные разборы** (только для активных) — вертикальный список
- **Подарите подруге** — реферальный баннер

### 4.10. Каталог 🆓

**Путь:** таб «Каталог» (второй)

**Что на экране:**

- Фильтры: Все / Классика / Психология / Пакеты / Бесплатные (горизонтальная лента)
- Баннер пакета «Пакет Отношения — 5 книг, −40%»
- Сетка книг (2 колонки): обложка-градиент, бейдж (бесплатно/куплено), название, автор, длительность, цена

**Действия:**
- Нажатие на книгу → экран книги (бесплатной, платной или купленной)
- Фильтр → показывает только соответствующие книги

### 4.11. Поиск 🆓

**Путь:** каталог → нажатие на строку поиска

**Что на экране:**
- Поле ввода с автофокусом

### 6.2.1. Качество кода — требования Apple (неявные)

Apple не проверяет исходный код, но отклоняет за РЕЗУЛЬТАТ плохого кода:

**Критичные (reject):**
- Crash при запуске, при навигации, при покупке — нулевая толерантность
- Placeholder-контент (Lorem ipsum, TODO, пустые экраны)
- «Web wrapper» — приложение не должно выглядеть как обёрнутый сайт
- Использование private APIs — гарантированный reject
- Устаревший Xcode SDK — может не пройти processing

**Важные для качества (снижают риск rejection):**
- **Быстрый старт:** холодный запуск < 3 секунд. Splash screen → данные
- **Обработка ошибок:** каждый HTTP-запрос имеет try/catch, показывает осмысленную ошибку
- **Оффлайн:** приложение не падает без сети, показывает экран 4.38
- **Memory:** нет утечек памяти, особенно в плеере и чате (долгие сессии)
- **Нативный вид:** используем стандартные iOS-паттерны (swipe back, pull to refresh, sheet dismissal)

**Наши правила для чистого кода (экономия токенов при AI-разработке):**
- Один файл = одна ответственность (SRP)
- Нет дублирования: общие виджеты в `shared/widgets/`, общие сервисы в `core/`
- Все строки UI — в одном месте (для будущей локализации)
- Все цвета/шрифты — ТОЛЬКО из дизайн-системы, никогда хардкод
- Zod-валидация на каждом эндпоинте — не доверяем входным данным
- Riverpod на Flutter — предсказуемый state management, нет widget rebuild hell
- Именование: `feature_name/screens/`, `feature_name/providers/`, `feature_name/widgets/`

**Продукты в App Store Connect:**

| Product ID | Тип | Описание |
|-----------|-----|----------|

| `archive.forever` | Non-Consumable | Вечный доступ к архиву |

**Subscription Group:** один — «Клуб ЧИТАТЕЛЬ». Внутри 2 уровня:
- Level 1: Премиум (выше)
- Level 2: Базовый (ниже)

Apple автоматически обрабатывает upgrade (Базовый → Премиум) и downgrade (Премиум → Базовый).

**Upgrade (Базовый → Премиум):**
- Происходит немедленно
- Apple рассчитывает пропорциональный возврат за оставшееся время Базового
- Пользователь сразу получает доступ к Премиум-функциям
- Бэкенд: S2S notification `DID_CHANGE_RENEWAL_INFO` → обновить `subscription_tier`

**Downgrade (Премиум → Базовый):**
- Вступает в силу со следующего периода оплаты
- До конца текущего периода сохраняется Премиум-доступ
- Бэкенд: S2S notification `DID_CHANGE_RENEWAL_INFO` с `autoRenewProductId` → запланировать переключение

**Crossgrade (месячный → годовой и обратно):**
- Тот же уровень — Apple обрабатывает как upgrade/downgrade в зависимости от стоимости
- Пользователь видит информацию о пропорциональной стоимости в системном диалоге Apple

**Отмена подписки:**
- Пользователь отменяет через Настройки iOS → Подписки (НЕ в приложении)
- Доступ сохраняется до конца оплаченного периода
- Бэкенд: S2S notification `DID_CHANGE_RENEWAL_INFO` с `autoRenewStatus: false`
- После истечения: S2S notification `EXPIRED` → переключить на Guest-состояние

**Серверная верификация:**
1. Flutter получает `JWS` (JSON Web Signature) после покупки
2. Отправляет на бэкенд: `POST /api/purchases/verify`
3. Бэкенд проверяет подпись через Apple App Store Server Library (Node.js)
4. Сохраняет транзакцию в MongoDB
5. Обновляет `subscription_status` пользователя
6. Слушает Server-to-Server Notifications V2 для обновлений (продление, отмена, billing retry)

**Grace Period:**
- Включить в App Store Connect (6 дней для годовой, 3 дня для месячной)
- В grace period пользователь сохраняет доступ, Apple пытается списать оплату
- Бэкенд: если `expirationDate` прошла но `gracePeriodExpiresDate` нет → доступ сохраняется

**Оффлайн:**
- StoreKit 2 кеширует статус подписки на устройстве
- Приложение может проверить `Transaction.currentEntitlements` без сети
- Бэкенд синхронизируется когда сеть появится

### 7.2.1. Flutter — архитектура и структура проекта

**Почему Flutter НЕ нужна классическая MVC-архитектура:**
Flutter — это декларативный UI-фреймворк. Вместо контроллеров и вьюх здесь виджеты + state management. Архитектура определяется тремя вещами:

1. **Riverpod** — state management (заменяет контроллеры)
2. **GoRouter** — навигация (декларативная, с guards)
3. **Feature-based структура** — каждая фича в своей папке

**Ключевой принцип:** виджет знает только что показывать. Откуда данные — решает провайдер. Куда сохранять — решает репозиторий.

**Правила для ИИ-агента при написании Flutter кода:**

1. **Новый экран** → `features/{feature}/screens/{name}_screen.dart`
2. **Новый провайдер** → `features/{feature}/providers/{name}_provider.dart`
3. **Виджет для 1 фичи** → `features/{feature}/widgets/{name}.dart`
4. **Виджет для 2+ фичей** → `shared/widgets/{name}.dart`
5. **Цвета** → ТОЛЬКО из `core/theme/app_colors.dart`, НИКОГДА хардкод
6. **Шрифты** → ТОЛЬКО из `core/theme/app_typography.dart`
7. **API вызов** → через `core/network/api_client.dart`, НИКОГДА raw http
8. **Навигация** → через GoRouter `context.go()` / `context.push()`, НИКОГДА Navigator
9. **State** → через Riverpod providers, НИКОГДА setState (кроме локальных анимаций)
10. **Модели** → fromJson/toJson в `shared/models/`, зеркалят backend schemas

**Riverpod-паттерн (конкретный пример):**
```dart
// features/diary/providers/diary_provider.dart

  return DiaryNotifier(ref.read(diaryRepositoryProvider));
```

### 7.6. Аудио

**Хранение:**
- Аудиофайлы хранятся на VPS в `/var/audio/chitatel/`
- Формат: MP3, 128 kbps (оптимальный для голоса), mono
- Именование: `book-{id}-part-{n}.mp3`
- ~50MB на книгу (4 части по ~60 мин)
- 100 книг = ~5GB — укладывается в диск VPS с запасом

**Раздача через nginx:**
```nginx
location /audio/ {
    internal;                           # Только через X-Accel-Redirect
    alias /var/audio/chitatel/;
    add_header Accept-Ranges bytes;     # Поддержка seek в плеере
    add_header Cache-Control "private, max-age=3600";
}
```

**Signed URLs:**
1. Flutter запрашивает `GET /api/books/:id/audio/:partNumber`
2. Бэкенд проверяет: подписка / покупка / бесплатный
3. Генерирует signed URL с HMAC и TTL (1 час):
   ```
   /audio/stream/book-123-part-1.mp3?token=abc123&expires=1709000000
   ```
4. nginx middleware проверяет token и expires
5. Если валидно — отдаёт файл через X-Accel-Redirect

**Для бесплатных книг:** URL без авторизации, но всё равно через signed URL (защита от прямого скачивания).

**Прогресс прослушивания:**
- Flutter отправляет позицию каждые 30 секунд: `POST /api/progress`
- При открытии книги: `GET /api/progress/:bookId` → восстановление с последней позиции
- Хранится в отдельной коллекции `Progress` (userId + bookId + partNumber + position)

### 7.7. ИИ-анализ (OpenAI)

**Анализ цитаты:**
1. Пользователь сохраняет цитату → `POST /api/quotes`
2. Если `aiConsent: true`, бэкенд ставит в очередь
3. Отправляет в OpenAI:
   - Модель: `gpt-4o-mini` (~$0.001 за анализ)
   - System prompt (хранится в `config/ai-prompts.js`):

**System prompt для анализа цитаты:**
```
Ты — Анна, основатель книжного клуба ЧИТАТЕЛЬ. Ты психолог по образованию и глубоко разбираешься в литературе.

Пользователь сохранил цитату из книги. Проанализируй её:

1. ПОЧЕМУ эта цитата могла откликнуться — что в ней может быть близко читателю на эмоциональном уровне (2-3 предложения)
2. КОНТЕКСТ — как эта мысль связана с основными идеями книги (1-2 предложения)
3. ВОПРОС ДЛЯ РАЗМЫШЛЕНИЯ — один глубокий вопрос, который поможет читателю применить эту мысль к своей жизни

Тон: тёплый, вдумчивый, как подруга которая очень любит книги. Не менторский. Не используй слова «важно заметить», «стоит отметить», «интересно что». Пиши естественно.

Ответ строго в JSON:
{
  "resonance": "...",
  "context": "...",
  "question": "..."
}
```

**System prompt для еженедельного отчёта:**
```
Ты — Анна из книжного клуба ЧИТАТЕЛЬ. За эту неделю читатель сохранил несколько цитат из книг.

Проанализируй паттерн:
1. ТЕМА НЕДЕЛИ — какая общая тема или настроение прослеживается в выборе цитат (2-3 предложения)
2. ЧТО ЭТО МОЖЕТ ЗНАЧИТЬ — мягкое наблюдение о том, что может занимать читателя сейчас (2-3 предложения)
3. РЕКОМЕНДАЦИЯ — одна книга из нашего каталога, которая может быть интересна на основе этих тем

Тон: заботливый, наблюдательный. Не психоанализ, а дружеское наблюдение.

Ответ строго в JSON:
{
  "weekTheme": "...",
  "insight": "...",
  "recommendation": { "title": "...", "author": "...", "why": "..." }
}
```

   - User message: текст цитаты + автор + название книги + последние 5 цитат пользователя (для контекста)
4. Парсит ответ → сохраняет в `quote.aiAnalysis`
5. Отправляет push: «Анализ цитаты готов»
6. Таймаут: 30 сек. Если OpenAI не ответил → retry 1 раз → если снова нет → помечает как failed, пользователь видит «Анализ временно недоступен»

**Еженедельный отчёт:**
1. Cron: каждое воскресенье 10:00 UTC+3
2. Для каждого пользователя с `aiConsent: true` и ≥ 1 цитатой за неделю
3. Собирает все цитаты за 7 дней
4. Отправляет в OpenAI для обобщённого анализа
5. Сохраняет как `WeeklyReport`
6. Push: «Еженедельный отчёт готов»

**Стоимость:** ~$0.001 на анализ цитаты + ~$0.005 на еженедельный отчёт. При 100 активных пользователях, 5 цитат/неделю каждый = ~$0.50/неделю + $0.50/неделю отчёты = ~$4/мес.

## 9. АДМИН-ПАНЕЛЬ АННЫ

### 9.1. Что это

Веб-интерфейс на `admin.chitatel.app` для управления контентом. Анна заходит через браузер, без установки приложений. Защищён паролем.

### 9.2. Функции

**Управление книгами:**
- Добавить новую книгу (название, автор, описание, категория, цена)
- Загрузить аудиофайлы (drag-and-drop, по частям)
- Установить градиент обложки (picker из готовых пар)
- Опубликовать / снять с публикации
- Редактировать описание

**Управление клубом месяца:**
- Создать новый клуб: выбрать книгу, даты, расписание частей
- Закрепить сообщение в чате
- Установить расписание открытия частей (часть 2 — 10 марта, часть 3 — 17 марта)
- Завершить клуб (архивировать)

**Ответы на Q&A:**
- Список неотвеченных вопросов
- Поле для ответа
- Публикация ответа → push участницам

**Модерация чата:**
- Список жалоб (отсортированы по дате)
- Просмотр сообщения + контекст (3 сообщения до и после)
- Действия: скрыть сообщение / предупреждение / бан пользователя
- Статистика: жалоб за неделю, скрытых сообщений

**Мысль дня:**
- Список запланированных мыслей
- Добавить новую: текст цитаты, автор, дата публикации
- Или автоматически из книги текущего клуба

**Push-уведомления:**
- Отправить кастомный push всем подписчикам
- Запланировать push на дату/время

**Статистика (базовая):**
- Всего пользователей / подписчиков / чат-сообщений
- Новых за сегодня / неделю / месяц
- Активных (заходили за 7 дней)

### 9.3. Технология

- Frontend: React + Tailwind (SPA)
- Хостится на том же VPS, nginx на поддомене `admin.chitatel.app`
- API: те же эндпоинты + `/api/admin/*` (защищены admin middleware)
- Аутентификация: логин/пароль → JWT с ролью `admin`

### 10.1. Рабочий процесс (GitHub-based)

**Документы в репозитории:**

| Файл | Назначение | Кто читает |
|------|-----------|-----------|
| `docs/MASTER.md` | Полная спецификация (этот файл) | ИИ — точечно нужную секцию |
| `docs/STEP-BY-STEP.md` | 40+ задач с файлами и критериями | ИИ — текущую задачу |
| `docs/AI-CONTEXT.md` | Краткий контекст для нового чата (30-50 строк) | ИИ — ПЕРВЫМ делом |
| `docs/prototype-v4_2.jsx` | Визуальный прототип всех экранов | ИИ — при работе над UI |

**Процесс каждого чата:**
1. Новый чат → ИИ читает `AI-CONTEXT.md` из GitHub (30-50 строк)
2. ИИ понимает: какая фаза, какая задача, что уже сделано
3. ИИ читает нужную задачу из `STEP-BY-STEP.md`
4. Если нужна деталь — ИИ читает конкретную секцию `MASTER.md`
5. Пишем код, тестируем, пушим
6. Обновляем `AI-CONTEXT.md` (что сделали, что следующее)

**Экономия:** ~300 строк контекста вместо 2500+ = больше места для кода.

## 11. ОБРАБОТКА ОШИБОК И EDGE CASES

### 11.1. Платежи

| Ситуация | Что показываем | Что делаем на бэкенде |
|----------|---------------|---------------------|
| Оплата не прошла (declined) | «Оплата не прошла. Попробуйте другой способ» + кнопка «Попробовать снова» | Логируем, не создаём purchase |
| Пользователь отменил оплату | Остаёмся на paywall, ничего не показываем | — |
| Подписка не продлилась | Экран «Подписка истекла» при входе (сценарий 3.6) | S2S notification → обновляем статус |
| Grace period | Доступ сохраняется, баннер «Проблема с оплатой» в профиле | Проверяем gracePeriodExpiresAt |
| Refund | Доступ отзывается немедленно | S2S REFUND notification → `status: 'refunded'` |
| Дублирование покупки | «Вы уже владеете этим контентом» | Проверка перед verify |
| Restore не нашёл покупок | «Покупки не найдены для этого Apple ID» | — |

### 11.2. Аудио

| Ситуация | Что показываем | Действия |
|----------|---------------|---------|
| Аудио не грузится | «Не удалось загрузить. Проверьте соединение» + retry | 3 автоматических retry с exponential backoff |
| Медленный интернет | Буферизация с индикатором (не замораживаем UI) | Адаптивная буферизация |
| Signed URL истёк | Прозрачный перезапрос нового URL | Flutter автоматически запрашивает новый URL |
| Сервер недоступен | «Сервер временно недоступен» + retry через 30 сек | — |
| Прогресс не сохранился | Сохраняем локально, синхронизируем при восстановлении сети | Локальный кеш позиции |

### 11.3. OpenAI / ИИ

| Ситуация | Что показываем | Действия |
|----------|---------------|---------|
| Таймаут (>30 сек) | «Анализ займёт больше времени» → push когда готов | 1 retry, потом в очередь |
| API недоступен | «ИИ-анализ временно недоступен. Цитата сохранена» | Цитата сохраняется без анализа, retry через 5 мин |
| Rate limit OpenAI | Невидимо для пользователя — очередь | Очередь с задержкой между запросами |
| Некорректный ответ | Не показываем плохой анализ | Валидация ответа, retry с уточнённым промптом |

### 11.4. Сеть

| Ситуация | Что показываем | Действия |
|----------|---------------|---------|
| **Первый запуск без сети** | Экран «Нет подключения» (4.38) с кнопкой «Повторить». НЕ показываем онбординг — нет данных для отображения | При появлении сети → нормальный онбординг. Apple тестирует на чистом устройстве — этот сценарий ОБЯЗАТЕЛЕН |
| Нет интернета при старте (не первый) | Экран «Нет подключения» (4.38) + кеш последних данных | Показываем кешированные книги, дневник. Кеш в SharedPreferences (ограниченный) |
| Потеря сети во время использования | Баннер вверху «Нет подключения» (не блокирует UI) | Автоматический retry при восстановлении |
| Потеря сети в чате | Сообщение помечается «Не отправлено» + retry | Очередь неотправленных сообщений |
| Потеря сети при оплате | StoreKit 2 обрабатывает сам (transaction queue) | Бэкенд получит верификацию позже |
| Потеря сети при ИИ-анализе | «Цитата сохранена. Анализ будет доступен при восстановлении сети» | Цитата в БД, анализ при reconnect |

### 11.5. Аутентификация

| Ситуация | Что показываем | Действия |
|----------|---------------|---------|
| Access token истёк | Ничего — прозрачный refresh | Interceptor в HTTP-клиенте |
| Refresh token истёк | Экран входа «Сессия истекла, войдите снова» | Очистка токенов, редирект на вход |
| Apple Sign In отозван | При следующем запросе → экран входа | Проверка `getCredentialState` при старте |
| Аккаунт удалён с другого устройства | «Аккаунт удалён» → экран входа | — |

## 12. БЕЗОПАСНОСТЬ

### 12.1. Аутентификация

- **JWT:** Access token (15 мин), Refresh token (30 дней, хранится в httpOnly cookie на веб, в Secure Storage на Flutter)
- **Пароли:** bcrypt, 12 rounds salt
- **Apple Sign In:** проверка identity token через Apple JWKS
- **Google Sign In:** проверка ID token через Google API
- **Refresh rotation:** каждый refresh выдаёт новую пару, старый инвалидируется

### 12.2. Rate Limiting (nginx + express)

| Эндпоинт | Лимит | Почему |
|----------|-------|--------|
| `/api/auth/*` | 10 запросов / мин с IP | Защита от брутфорса |
| `/api/quotes` (POST) | 30 / час с пользователя | Защита от спама в OpenAI |
| `/api/club/chat` (POST) | 60 / мин с пользователя | Защита от флуда в чате |
| `/api/purchases/verify` | 10 / мин с пользователя | Защита от replay |
| Все остальные | 100 / мин с пользователя | Общая защита |

### 12.3. Валидация данных

- **Zod** на всех входящих данных (body, params, query)
- Sanitization: `xss` пакет для UGC (чат, цитаты)
- Нет SQL injection (MongoDB), но защита от NoSQL injection (mongoose strict mode)

**Полная таблица лимитов контента:**

| Поле | Макс. длина | Где проверяем |
|------|------------|---------------|
| Цитата (текст) | 2000 символов | Zod + Flutter UI |
| Сообщение чата | 1000 символов | Zod + Flutter UI (счётчик) |
| Вопрос Q&A | 500 символов | Zod + Flutter UI |
| Имя пользователя | 100 символов | Zod + Flutter UI |
| Email | 254 символа (RFC) | Zod email validator |
| Пароль | 8–72 символа | Zod + Flutter (bcrypt макс 72 байта) |
| Фото профиля | 5 MB, JPEG/PNG | Multer file filter + Flutter image_picker |
| Фото в чате | 5 MB, JPEG/PNG | Multer + resize до 1200px на бэкенде |
| Жалоба (текст) | 500 символов | Zod + Flutter UI |
| App Store Review Notes | 4000 символов | App Store Connect |
| Кол-во цитат в день | 50 / день на пользователя | Rate limit middleware |
| Сообщений в чате | 60 / минута на пользователя | Rate limit middleware |
| Количество жалоб | 20 / день на пользователя | Rate limit middleware |

### 12.4. Защита аудио

- Прямой доступ к `/var/audio/` заблокирован (nginx `internal`)
- Signed URLs: HMAC-SHA256 + TTL 1 час
- Каждый URL привязан к `userId` — нельзя переиспользовать чужой URL
- Нет загрузки файла целиком — только стриминг (Range headers)
- Watermarking (post-MVP): аудио-метка с userId для отслеживания утечек

### 12.5. Защита данных

- **HTTPS:** обязательно везде (Let's Encrypt, auto-renew)
- **MongoDB:** аутентификация включена, bind только на localhost
- **Env vars:** `.env` файл, не в git. Secrets в переменных окружения
- **Бэкапы:** ежедневный `mongodump` → сжатие → хранение 30 дней
- **Логи:** не логируем пароли, токены, персональные данные
- **GDPR:** удаление аккаунта удаляет все данные за 24 часа. Экспорт данных — post-MVP

### 12.6. Helmet + CORS

```javascript
app.use(helmet());
app.use(cors({
  origin: ['https://chitatel.app', 'https://admin.chitatel.app'],
  credentials: true
}));
```

### 12.7. Мониторинг

- **PM2:** мониторинг процессов, автоперезапуск при crash
- **Логи:** `winston` → файлы + ротация (7 дней)
- **Uptime:** бесплатный мониторинг (UptimeRobot) — пинг каждые 5 минут, алерт в Telegram
- **Ошибки:** Sentry (бесплатный план) — crash-репорты с Flutter и бэкенда
